Free Setup — Groq API Key

Groq is completely free — no credit card, no cost. Takes about 60 seconds.

  1. 1
    Go to console.groq.com

    Click Sign Up — you can use Google or GitHub to log in instantly.

  2. 2
    Create an API Key

    In the left sidebar click API Keys → Create API Key. Name it anything.

  3. 3
    Copy & paste your key above

    Copy the key that starts with gsk_ and paste it into the Groq API Key field above.

  4. 4
    Click Save Settings & Test

    Hit Save Settings, then Test API Key to confirm it works. That's it!

Groq's free tier includes millions of tokens per day — more than enough for everyday use.

About

ClownFish Extension v2.0.0 — All-in-one document productivity tools.

  • Auto Typer — Simulates human typing with speed/randomness controls
  • AI Checker — Detects AI-generated content via GPT analysis
  • AI Rewriter — Humanizes text to reduce AI detection scores
  • AI Writer — Generates AI-written content from any prompt or selected text
  • Cite — Finds sources for your text and formats MLA/APA/Chicago citations
  • Fact Check — Identifies false or uncertain claims and highlights them in the page
